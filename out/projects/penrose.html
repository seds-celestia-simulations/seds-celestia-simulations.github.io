Penrose

Modular general-relativity framework for geodesic integration and real-time Schwarzschild ray tracing on CPU and GPU.

Status

Active

Timeline

Ongoing

Penrose is a modular General Relativity framework for simulating and visualizing particle and photon trajectories in curved spacetime. It began as a Schwarzschild black-hole ray tracer and is growing into a general-purpose stack for relativistic spacetime simulation, geodesic integration, validation, and scientific visualization.

What it does

  • Schwarzschild spacetime implementation
  • Relativistic photon ray tracing (null geodesics)
  • Fourth-order Runge–Kutta geodesic integration
  • CPU reference physics pipeline for correctness
  • GPU real-time visualization via OpenGL / GLSL
  • Scientific benchmarking and validation against analytic constraints

Validation KPIs

CPU benchmarks include radial free-fall (relative error under 0.05%0.05\%0.05% vs analytic proper time) and circular-orbit invariant checks. Energy EEE, angular momentum LLL, and the geodesic norm stay within ∼10−6\sim 10^{-6}∼10−6 drift over millions of steps at dt=0.01dt = 0.01dt=0.01.

Why dual pipelines

CPU path is ground truth for science. GPU path is the live window into curved spacetime. They share the physics model, not the implementation — so interactive visuals never redefine correctness.

Engineering notes

  • Fixed GPU timestep — adaptive RKF45 reduces flat-space work but causes warp divergence; fixed hhh keeps SIMT coherent.
  • fp32 on GPU — fine for visualization; near-horizon rounding accumulates over ∼1000\sim 1000∼1000 steps.
  • Memory — procedural geometry + particle SSBO stays under ∼50\sim 50∼50 MB.
  • Disk model — kinematic point particles today, not radiative transfer.

Roadmap

Evolve from a Schwarzschild-specific renderer into a modular GR framework. Planned geometries include Kerr, Reissner–Nordström, FLRW, Solar Gravitational Lens, user-defined analytic metrics, and numerical metric fields — plus fp64 / adaptive integrators, redshift & Doppler effects, and physically motivated accretion disks.
